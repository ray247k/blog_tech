把程式上傳到 Lambda 服務裡，有網路封包傳入請求存取時快速啟用
達成用多少付多少的目的

核心結構

Enent

當外部用戶或是 AWS 服務有請求時，發送 Enent 給 Lambda

Trigger

在 Lambda 裡面負責接收 Event，會啟動相應的 Function

Function

用來處例 Enent，並且可以配置 IAM Role 讓 Function 可以調度其他 AWS Resource

版本控管

透過 Version 做版本控管，可以發布新版本進行 Beta 測試而不影響正式環境

可透過 Alias 對不同環境指定不同 Version

計費

  • 記憶體越大，Lambda 運算能力越強，收費越貴
  • 運算時間越長，費用就越高

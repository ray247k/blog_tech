作為應用程式的「前門」，以便從後端服務存取資料、商業邏輯或功能
使用 API Gateway 時，您可以建立 RESTful API 和 WebSocket API，以啟用即時雙向通訊應用程式
API Gateway 支援容器化、無伺服器工作負載和 Web 應用程式

大型資訊架構內有多個資訊系統，如果讓用戶分別存取不同的系統
除了曝露過多介面給用戶的風險外，外部用戶在調度時 API 路徑過於碎片化

這時候就需要一個整合性接口作為前門，AWS 推出 API Gateway 服務

在 GCP 上建立 Redis 服務

透過 Google Cloud MemoryStore 建立 Redis 服務

2022/06/30

Ray

GCP 提供 Google Cloud MemoryStore 服務可用來建立 Redis 或是 Memcached 快取機器服務
價錢跟開 Database 差不多，原本以為跟 VM 一樣便宜

建立 Redis

進入MemoryStore頁面點選則「Redis」或是「Memcached」就可以開始建立了

這邊以 Redis 為例，點選「建立執行個體」

輸入一些基本設定，基本上就是調整大小跟名稱而已

照提示選項設定完之後按下「建立執行個體」接著就是等他建立好了
這邊會要稍微等待，可以稍微去休息一下

以上就是在 GCP 上建立 Redis 的方法
只需要將應用程式中的端點對應到 Redis 執行個體的 IP 就可以使用
也可以直接使用第三方 GUI，比如 Another Redis Desktop Manager 進行 IP 連線來查看執行個體的內容
